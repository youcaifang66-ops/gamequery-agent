# GameQuery 十次迭代路线

1. `v0.1` 游戏数仓 MVP：Python 3.12、游戏元数据、种子数据、前端示例与契约测试。
2. `v0.2` 指标语义层：DAU、留存、收入、付费率、ARPU 的定义与计算口径。
3. `v0.3` 多路召回：Qdrant、Elasticsearch、LLM 扩展、融合排序与可解释得分。
4. `v0.4` SQL AST 护栏：只读、表字段白名单、LIMIT、超时和敏感字段策略。
5. `v0.5` 有限修正：错误分类、最多重试、原始问题与数据库反馈联合修复。
6. `v0.6` Text-to-SQL 评测：执行正确率、结果一致性、延迟和成本回归。
7. `v0.7` 轨迹持久化：检查点、会话恢复、失败回放与审计。
8. `v0.8` API 工程：SSE 事件协议、并发、取消、权限与限流。
9. `v0.9` 产品化：可视化结果、Docker、CI、日志、指标与演示数据。
10. `v1.0` 面试版本：在线演示、架构文档、压测报告和深挖问答。

根目录的《GameQuery_十次迭代路线.md》记录每次提交的详细验收口径。
